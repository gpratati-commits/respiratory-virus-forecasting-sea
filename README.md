# Multi-Pathogen Respiratory Virus Forecasting in Southeast Asia

## Project overview

This project investigates the epidemiology and short-term forecasting of major respiratory pathogens across tropical Southeast Asian settings.

The project focuses on:

- Influenza
- Respiratory syncytial virus (RSV)
- SARS-CoV-2

## Main research question

How accurately can respiratory virus activity be forecast 1–4 weeks ahead, and do climatic, seasonal, and cross-pathogen signals improve forecasts beyond recent disease activity alone?

## Planned workflow

1. WHO respiratory surveillance data
2. Data-quality assessment
3. Country and study-period selection
4. Clean master dataset
5. Exploratory analysis and seasonality
6. Cross-pathogen analysis
7. ERA5 climate data
8. Climate-lag analysis
9. Forecast design
10. Baseline forecasting
11. GAM/statistical modelling
12. XGBoost
13. Forecast evaluation
14. SHAP interpretation
15. Rt estimation
16. Bayesian hierarchical modelling
17. SIRS modelling
18. Probabilistic forecasting
19. Ensemble forecasting
20. Sensitivity analysis
